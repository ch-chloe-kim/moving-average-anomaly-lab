개념 이해

이동평균 이상 탐지란?

"평소 수준"을 고정된 숫자로 정하지 않고, 바로 직전 N개 시점의 평균으로 계속 새로 계산합니다. 새 값이 이 기준선에서 허용 범위보다 많이 벗어나면 이상으로 판정합니다.

  1. 처음 N개 시점은 평균 낼 데이터가 부족해 판단 보류
  2. 기준선 = 직전 N개 값의 평균 (현재 값은 넣지 않음)
  3. 편차 = |현재 값 − 기준선|
  4. 편차 > 허용 범위 → 이상 (위로 벗어나면 급증, 아래로 벗어나면 급감)
  5. 편차가 허용 범위와 정확히 같으면 정상
동작 원리

의사코드

각 시점 t에 대해:
  t ≤ N 이면: 판단 보류(워밍업)
  아니면:
    창 ← 직전 N개 값
        (옵션: 이상값은 건너뛰고 정상값 N개)
    기준선 ← 창의 평균
    허용 ← 고정값 또는 기준선 × p%
    편차 ← |x_t − 기준선|
    편차 > 허용 이면:
      x_t > 기준선 → 급증, 아니면 급감
    아니면: 정상
장점과 한계

언제 잘 맞고, 언제 틀릴까?

장점

  • 계산이 단순하고 빨라 실시간 감시에 적합
  • 판정 이유를 숫자로 설명하기 쉬움
  • 데이터 수준이 바뀌면 기준선이 자동으로 따라감

한계 (예제로 직접 확인)

  • 기준선 오염: 이상값이 평균에 섞이면 다음 정상값까지 이상으로 오판 → 「기준선 오염 비교」
  • 드리프트: 조금씩 꾸준히 오르면 기준선이 따라가서 못 잡음 → 「한계: 서서히 증가」
  • 워밍업: 처음 N개는 판단 불가
  • N 선택: 작으면 작은 흔들림에도 경보, 크면 반응이 느림
  • 계절성 미반영: 매일 저녁 피크처럼 "예정된 급증"도 이상으로 볼 수 있음
산업 활용

현업에서는 어떻게 쓸까?

  • Amazon CloudWatch 이상 탐지 — 지표의 정상 범위(밴드)를 만들고 벗어나면 경보. 배포 같은 비정상 구간을 학습에서 제외 가능
  • AWS 블로그 — 온라인 주문이 예상 기준선 아래로 떨어지면 자동 조치하는 동적 알람
  • Datadog Anomaly Monitor — 가장 단순한 basic 알고리즘이 롤링(이동) 방식으로 예상 범위 계산

실제 서비스는 계절성·추세까지 반영한 통계·머신러닝 모델을 씁니다. 이 시뮬레이터는 그 핵심 아이디어(최근 데이터로 만든 기준선 + 허용 범위)를 단순화한 교육용입니다.

모든 계산은 내 브라우저 안에서만 이루어집니다.
