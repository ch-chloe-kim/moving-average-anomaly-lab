# 손계산 답지 — 테스트 1 (기본 예제)

## ① 문제 조건
데이터: 100, 110, 90, 105, 300, 95, 100, 20, 105, 110
N = 3, 임계값 = 50 (고정), 이상값 제외 옵션 끔
규칙: 기준선 = 직전 3개 평균 / 편차 = |값 − 기준선| / 편차 > 50 → 이상 (같으면 정상)

## ② 시점별 계산
t=1, 2, 3 (100, 110, 90) → 워밍업 (직전 값이 3개 미만)

t=4 (값 105)
  기준선 = (100 + 110 + 90) ÷ 3 = 300 ÷ 3 = 100
  편차   = |105 − 100| = 5
  판정   = 5 ≤ 50 → 정상

t=5 (값 300)
  기준선 = (110 + 90 + 105) ÷ 3 = 305 ÷ 3 = 101.7
  편차   = |300 − 101.7| = 198.3
  판정   = 198.3 > 50 → 이상, 300 > 101.7 → 급증

t=6 (값 95)
  기준선 = (90 + 105 + 300) ÷ 3 = 495 ÷ 3 = 165
  편차   = |95 − 165| = 70
  판정   = 70 > 50 → 이상, 95 < 165 → 급감
  메모   : 300이 평균에 들어가 기준선이 올라감 → 오탐

t=7 (값 100)
  기준선 = (105 + 300 + 95) ÷ 3 = 500 ÷ 3 = 166.7
  편차   = |100 − 166.7| = 66.7
  판정   = 66.7 > 50 → 이상, 급감
  메모   : 300이 아직 창 안에 있음 → 오탐

t=8 (값 20)
  기준선 = (300 + 95 + 100) ÷ 3 = 495 ÷ 3 = 165
  편차   = |20 − 165| = 145
  판정   = 145 > 50 → 이상, 급감 (진짜 이상)

t=9 (값 105)
  기준선 = (95 + 100 + 20) ÷ 3 = 215 ÷ 3 = 71.7
  편차   = |105 − 71.7| = 33.3
  판정   = 33.3 ≤ 50 → 정상

t=10 (값 110)
  기준선 = (100 + 20 + 105) ÷ 3 = 225 ÷ 3 = 75
  편차   = |110 − 75| = 35
  판정   = 35 ≤ 50 → 정상

## ③ 결과 정리
급증: 5 / 급감: 6, 7, 8 (6·7은 오탐) / 정상: 4, 9, 10 / 워밍업: 1~3
→ 이상 4건 (급증 1, 급감 3)

## ④ 시뮬레이터 대조
「기본 예제 → 끝까지」 결과 카드: 급증 1 / 급감 3 / 정상 3 / 워밍업 3 → 모두 일치 ✔
